# COTIZADOR-REPARACIONES

Base de precios inteligente para BLACK TECH.

## Objetivo V1

Permitir consultar rápidamente cuánto cuesta una reparación y calcular precios de referencia para cobrarla.

La aplicación está pensada para:

- Registrar referencias de repuestos una sola vez.
- Asociar una referencia con uno o varios proveedores.
- Comparar costos entre proveedores.
- Calcular precio mínimo, recomendado y premium.
- Mantener la información reutilizable para futuras cotizaciones.
- Funcionar en PC y celular.

## Estado

V1 inicial: aplicación web responsive con almacenamiento local y exportación/importación de datos. La persistencia sincronizada entre dispositivos se incorporará posteriormente sin cambiar el concepto del sistema.

## Nota

Los márgenes iniciales de precio son configurables y provisionales. Deben ajustarse a las reglas reales de BLACK TECH antes de usarlos como precios definitivos.
